# First session

Document the actual player journey before expanding the world. For each state record the entry
condition, what the player sees, the action they take, feedback and recovery, and the next state.
Include arrival, first action, first success, core loop, stage changes, failure recovery, finish,
replay/return and returning players. Name the intended visual direction and the arrival/play/payoff
compositions. Validate through real input from a clean launch, with phone and desktop captures.
